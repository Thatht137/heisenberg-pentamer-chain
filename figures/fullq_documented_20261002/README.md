## 色标与图注

线性对照采用 u=S/6；S 表示 J1*Szz(q,omega)。
增强版采用 u=asinh(S/0.1)/asinh(6/0.1)。
两组参数在各自显示模式下共用同一映射和 0 至 6 的色标；色条刻度为实际谱强度而非变换后的数值。
原始峰值和零值保留，数据没有超出色标范围；未针对高能区单独压暗。
非线性色标会改变视觉突出程度和表观带宽。谱权重比、峰宽、能隙等定量分析须使用原始数值。

可直接使用的增强版图注：

> L=40 五聚体 Heisenberg 链的连通动态结构因子 Szz(q,omega)。整图采用统一 asinh 强度色标（s0=0.1，范围 0 至 6），色条显示实际 J1*Szz 数值，两组参数共用同一映射。坐标轴保持线性，原始谱未作高斯平滑、插值或镜像平均。谱来自 T=60 的演化及三角时间窗，窗口 FWHM 约 0.09277J1。增强仅用于显示弱谱权，不代表能量分辨率提高；弱条纹可能包含有限时间窗旁瓣。

线性对照图注可将上述色标说明替换为“整图采用共同的线性强度色标，范围 0 至 6”。
