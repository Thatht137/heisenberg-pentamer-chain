\section{引言}

团簇化量子自旋链为研究局域多重态、量子临界性、隐藏弦关联和边缘自由度之间的
关系提供了可控平台。已有四聚体链研究建立了“孤立单胞多重态—弦关联—纠缠结构—
动力学结构因子”的证据组织方式，并展示了不同耦合区域的低能激发特征
\cite{li2026tetramer}。然而，五聚体单胞包含奇数个自旋 $\frac{1}{2}$，
其低能自由度和 Lieb--Schultz--Mattis 类型约束与偶数自旋单胞不同，因此不能
直接移植四聚体链的相名、弦算符端点或准粒子命名。

本文考虑具有两个胞内耦合 $J_1,J_2$ 和胞间耦合 $J_3$ 的五聚体
Heisenberg 链，并将研究范围限制在 $\alpha=J_2/J_1\geq0$ 和
$\beta=J_3/J_1\geq0$。参考四聚体工作的图像不能直接用于这一范围：五聚体
基态单胞是半整数自旋双重态，因而弱胞间耦合首先作用于未淬灭的有效自旋，
而不是在整数自旋团簇之间传播局域三重态。

本文围绕三个相互约束的问题组织证据：

\begin{enumerate}
  \item 孤立五聚体的低能双重态如何投影为链上的有效自由度；
  \item 正胞间耦合下的有限链是否与 $c=1$ 反铁磁 Heisenberg 链一致；
  \item 局域多重态的宇称与总自旋如何限制 $S^{zz}(q,\omega)$ 的可见通道。
\end{enumerate}

我们先以孤立单胞投影和两单胞精确对角化建立有效理论，再以多尺寸 DMRG 和
同尺寸 Heisenberg oracle 检查其有限链后果，最后用局域投影谱权为长链动力学
提供分支先验。修正向量 DMRG 在精确可解的小系统上逐点验收后才扩展到较大长度。
该路线确立正耦合区的低能机制和局域选择定则，但不把有限尺寸侦察图解释为已经
完成的二维相图或热力学极限谱。
