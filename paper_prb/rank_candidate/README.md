## 相比旧稿的实质变化

旧稿主要是局域自旋投影、有效链和折叠谱权，这些本身不能支撑充分原创性。新稿的具体问题是：调整微观耦合，抵消投影主响应及其一阶修正后，还能否消除整条低能带的强度？

在规定的周期、反演和单一局域自旋表示条件下，双重态的一阶修正仍与单自旋探针成比例，可以整体消掉；四重态允许额外的四极矩乘邻居自旋的矢量项，不一定能消掉。相同十五自旋周期几何的微观计算分别给出约二次方和四次方的耦合依赖，并对最弱信号做了复算。四胞周期链的零结果也保留为反例，不能说四重态必然有残余。

**这是有数据支持的新贡献候选，不是“已证明首创”或“已达到最终投稿”的标签。** 方法本身属于已有有效算符和张量理论。2005 年的相关有效散射算符工作已在新稿中明确引用。
