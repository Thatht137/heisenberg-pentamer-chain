## 2. 当前可形成的贡献表述

在已有本地证据范围内，较稳妥的新颖性是“模型特定的低能投影和选择规则验证”，而不是“首次发现某种普适准粒子或新相”：

1. **奇数五聚体单胞的低能投影。** 在已核验的正区 `0<alpha<=1`，孤立五聚体 ED 给出基态双重态；投影
   `P S_{n,a} P = c_a T_n` 后，弱胞间耦合产生有效反铁磁 S=1/2 链。两胞 ED 与多尺寸数据把首个系统修正限制为 `O(beta^2)`。这与三聚体文献的逻辑同源，但系数、反射结构和局域能级是五聚体自己的结果。
2. **五站点内部形状因子与可见/暗通道。** 五聚体的五个投影系数、反射奇偶性和局域 `S=3/2`/`S=1/2` 通道可以作为本模型的可检验微观指纹；它不是对三聚体 doublon/quarton 或四聚体 triplon/quinton 名称的替换。
3. **方法链条的可复现闭环。** 单胞 ED、两胞 oracle、DMRG/MPS、纠缠 oracle、correction-vector 与 TEBD 交叉检查构成方法链；文献只提供方法和比较基线，数值门仍由项目数据独立承担。

## 3. 仍然不能写入结论的内容

| 说法 | 当前边界 |
|---|---|
| “发现新的相”或“负 `alpha` 是新相” | 不可写。近零负区的 8-spin 构造是 trimer-dimer-trimer 局部模型，不是完整两五聚体链；完整链的形状因子和两点观测量仍待验证。 |
| “全参数域是单一相” | 不可写。有限网格没有热力学极限全域证明；缺失区域、边界效应和收敛对照仍需补齐。 |
| “Haraldsen 的五聚体就是本项目模型” | 不可写。PubMed/APS 摘要显示其为一般 `S-S'` 对称五聚体、特殊 `1-1/2` mixed-spin INS 例；本项目是 all-spin-1/2 开放边界线性键。未读全文几何图，不能声称键拓扑已完成比对。 |
| “三聚体已证明五聚体同样有相同高能准粒子” | 不可写。Cheng 等人的框架可作最近类比，但五聚体的反射选择规则、谱权和局域多重态必须独立计算。 |
| “`c=1` 已完成无偏热力学外推” | 不可写。当前只能写 matched-size Heisenberg oracle 校准后的有限尺寸一致性。 |
| “CV/TEBD 已验证完整全 `q` 生产谱” | 不可写。正区已有三组 `dt/dt2` full-q pairs；CV 对照仍只代表同一参数点的 `q=pi`。这不覆盖负区，也不等于新 L80 结果已验收。 |

## 4. 近期最小补证据

- 对完整五聚体链在相同参数点复核五站点形状因子，而不是只由孤立单胞公式推断。
- 对局部近零机制与完整链分别报告几何、边界、初态和观测量，避免把局部通过写成全链通过。
- 对两点观测量（纠缠窗口与 gap/bond correlations）做预定义窗口、同 bond 位置和双初态的稳定性比较；不另设任意“随机百分比”通过门。
- 对动态结果继续保留 correction-vector residual、TEBD `dt/dt2`、负权与覆盖门；文献不能替代这些数值验收。

结论：文献比较支持本项目的“奇数自旋单胞—有效半整数链—模型特定局域选择规则”定位；现阶段不足以支持新相、全域单相、全链新机制或热力学极限完成的表述。
