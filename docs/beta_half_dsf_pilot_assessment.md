# `beta=0.5` 五点试验性 DSF 评估

## 计算参数

本轮目的是识别值得进一步做尺寸标度的低能动量结构，不用于最终判相。

```text
alpha = -0.50, -0.05, 0.14, 0.23, 0.33
beta = 0.5
L = 40
dt = 0.05
tmax = 15
DMRG/TEBD maxdim = 160
q points = 81
omega points = 181
```

时间窗给出的频率分辨尺度约为

```text
2*pi/tmax ≈ 0.42 J1
```

因此 `omega≈0` 的谱重只能视为软模候选，不能据此单独证明热力学极限无隙。

## 初步观察

### 负 `alpha` 深处

`alpha=-0.50` 的最低频谱重集中在 `q≈0.6*pi`，而不是静态结构因子的
主峰 `q=pi`。对于五站点单胞，有效单胞动量 `K=pi` 可以折叠到

```text
q = (2m+1) pi / 5
```

因此 `q≈3*pi/5` 的软模可能来自有效半整数单胞自由度。结合孤立五聚体在
负 `alpha` 下具有最低 `S=3/2` 多重态，这一结果更接近有效半整数反铁磁链
的低能图像，而不是已经确认的普通有隙 Haldane 链。

这与此前基于弦关联、边缘磁化和纠缠低能簇给出的 SPT-like 解释形成张力。
当前不能删除任何一组证据；更合理的做法是重新检查负侧是否属于临界且带有
非平庸边缘/弦关联特征的状态，或者有限尺寸弦序是否尚未进入渐近衰减区。

### 负 `alpha` 近零点

`alpha=-0.05` 的低能谱重较弱且分散，当前 `L=40,tmax=15` 无法可靠确定
软模位置。该点靠近八重单胞简并，预计需要更长时间演化和更大的系统。

### 正 `alpha`

`alpha=0.14,0.23,0.33` 均在 `q≈pi` 附近出现明显低频谱重，且
`alpha=0.23,0.33` 最强。这与正侧自旋隙趋零、实空间关联幂律衰减以及
静态结构因子主峰保持在 `q=pi` 的结果一致。

三个正 `alpha` 点的低能动量位置没有显示出在 `0.17` 或 `0.30` 两个
响应尺度之间发生突变，因此试验性 DSF 仍不支持独立第四相。

## 对 Li 等文献范围的影响

Li 等用低能 DSF 连续谱支持四聚体中间区的解禁闭 spinon。当前五聚体谱只
显示软模与谱重重分配，尚未得到连续谱上下边界、尺寸稳定性或五聚体专用
spinon 有效图像，所以仍不能使用“解禁闭临界态 III”作为相名。

更重要的是，五聚体的奇数自旋单胞可能让负、正两侧都保留半整数低能自由度，
这正是不能直接复制四聚体三相图的原因。

## 下一步判别顺序

1. 对 `alpha=-0.50,-0.05` 增加 `L=40,60,80` 自旋隙标度；
2. 对相同负侧点计算实空间自旋关联，比较幂律和指数衰减；
3. 对 `alpha=-0.50` 与 `alpha=0.23` 做至少两个尺寸或两个 `tmax`
   的 DSF，检查软模是否稳定；
4. 若负侧能隙也趋零，修改 Results 主线为“两类无隙区域在
   `alpha=0` 重组”，再研究弦关联和边缘响应是否定义临界 SPT 特征；
5. 只有获得连续谱尺寸标度和有效自由度后，才讨论 spinon。
