# `beta=0.5` 候选中间相评估

## 问题

能量曲率在 `alpha≈0.17` 附近出现峰，纠缠熵响应在
`alpha≈0.30` 附近出现峰。需要判断两者之间是否存在独立第四相。

## 已完成判据

### 自旋能隙

对 `alpha=0.10–0.50` 的多个参数点进行 `L=40,60,80`
有限尺寸外推。所有正 `alpha` 点的自旋能隙均趋近于零。

这排除了区间 `0.17≲alpha≲0.30` 是普通有隙相的解释。

### 最近邻键关联

在 `L=100`、`beta=0.5` 下加密扫描

```text
alpha = 0.10, 0.14, 0.17, 0.20, 0.23,
        0.27, 0.30, 0.33, 0.40, 0.50
```

结果显示：

- `J1`、`J2` 和 `J3` 三类体区键关联均连续变化；
- `alpha≈0.17` 和 `alpha≈0.30` 附近没有跳变或键强度重排；
- 左右 `J1` 键差和左右 `J2` 键差约为 `10^-9–10^-7`；
- 没有发现自发二聚化或新的五聚体内部对称性破缺。

对应结果：

```text
data/bond_correlations/bulk_summary_b0.5_L100.csv
figures/bond_correlations_b0.5_L100.pdf
```

### 静态结构因子

在 `alpha=0.14,0.23,0.33` 三个代表点计算 `L=100`
静态自旋结构因子。三个点的主峰均位于

```text
q_peak / pi = 1.0000
```

峰高从 `3.390` 连续增加到 `4.065`，但没有主峰分裂、移动或
非公度化。因此候选区间两侧具有相同的主导反铁磁波矢。

对应结果：

```text
data/static_structure_factor/peak_summary_b0.5_L100.csv
figures/static_structure_factor_b0.5_L100.pdf
```

### 实空间关联标度

对 `alpha=0.14,0.23,0.33` 计算 `L=40,60,80` 的体区平均
连接自旋关联，并拟合

```text
(-1)^r C(r) ∝ r^(-eta)
```

`L=80` 的拟合指数分别为

```text
alpha=0.14: eta=0.978±0.064
alpha=0.23: eta=0.962±0.037
alpha=0.33: eta=0.948±0.020
```

三个参数点的指数连续且彼此相容，没有在两个响应峰之间发生突变。
随着尺寸从 `L=40` 增大到 `L=80`，幂律拟合逐渐优于指数衰减
拟合。`L=80` 时指数拟合的对数残差分别是幂律拟合的
`1.30、1.67、2.52` 倍。

对应结果：

```text

figures/spin_correlation_scaling_b0.5.pdf
```

### 初步纠缠谱

在 `L=80` 下计算 `alpha=-0.50,-0.05,0.14,0.33` 的中心五种
切口纠缠谱。结果具有明显切口依赖：

- 负 `alpha` 的单元边界切口 `cut=0` 出现近似成对低能级；
- 正 `alpha` 的无隙态同样出现 SU(2) 多重态简并；
- 因此无量子数标签的“双重简并”不能单独作为 SPT 证据；
- `alpha=-0.50` 的低能劈裂仍较明显，需要尺寸和收敛检查。

对应结果：

```text
data/entanglement_spectrum/splitting_summary_b0.5_L80.csv
figures/entanglement_spectrum_b0.5_L80.pdf
```

仍需提取 Schmidt 态的 `Sz` 量子数，并与下述边缘磁化共同判断
负 `alpha` 区域是否为 Haldane/SPT 相。

对 `alpha=-0.50` 和 `alpha=0.14` 进一步提取 Schmidt 态的
`Sz` 标签。结果表明：

- 偶数格点切口出现整数 `Sz` 扇区，奇数格点切口出现半整数扇区；
- 正 `alpha` 的精确简并组成标准 SU(2) 多重态，不能视为拓扑简并；
- `alpha=-0.50` 的单元边界切口最低四级由
  `Sz=0,+1,0,-1` 组成近简并 singlet–triplet 簇；
- 该低能簇与下述两端局域自旋一致，但仍不是完整的投影表示计算。

带量子数的对照图为：


### 边缘磁化

在总 `Sz=1` 扇区，对
`alpha=-0.50,-0.05,0.14,0.33` 计算 `L=40,60,80`
的局域磁化。

`alpha=-0.50` 显示清晰的两端局域磁化：

- 左右累积磁化快速振荡收敛到约 `1/2`；
- 前后各十个格点的总边缘权重为
  `0.879,0.858,0.849`；
- 边缘权重的幂律尺寸指数仅为 `gamma≈0.05`，接近尺寸无关。

正 `alpha` 的磁化分布在整个链中：

- `alpha=0.14` 的十格点边缘权重为
  `0.636,0.473,0.382`，`gamma≈0.73`；
- `alpha=0.33` 的对应结果为
  `0.518,0.362,0.285`，`gamma≈0.86`。

因此深负 `alpha` 区域具有稳定边缘自旋，而正 `alpha` 无隙区域的
固定宽度边缘权重随尺寸衰减。

`alpha=-0.05` 的结果不单调，并出现明显左右不对称和体区磁化。
这可能来自靠近 `alpha=0` 时很大的关联长度、低能态近简并或 DMRG
落入不同低能组合。该点不能用于定位拓扑边界，需要增加尺寸、
初态和扫描连续性检查。

对应结果：

```text

data/edge_magnetization/edge_extrapolation_b0.5.csv
figures/edge_magnetization_b0.5.pdf
figures/edge_weight_scaling_b0.5.pdf
```

### `alpha≈0` 多初态收敛

在 `L=60`、总 `Sz=1` 扇区，对

```text
alpha=-0.15,-0.10,-0.075,-0.05,-0.025,0
```

分别使用中心、左端和右端磁化初态。

结果显示：

- 所有负 `alpha` 点均由右端初态得到最低能量；
- 左右初态本应由反演对称性等价，但能量差在靠近零点时达到
  `10^-4–5×10^-4`；
- 因此此前 `alpha=-0.05` 的异常主要来自 DMRG 初态和扫掠方向
  偏置，而不能解释为新相；
- 每个负 `alpha` 点当前找到的最低能态，其十格点边缘权重均为
  `0.90–0.93`；
- `alpha=0` 出现大量精确简并和极低 MPS 键维，是一个特殊解耦点。

最低能量包络支持边缘态持续到 `alpha=0` 的负侧。当前最保守的
边界判断是

```text
alpha_c = 0
```

但靠近零点的能量误差应取至少 `5×10^-4`，正式边界结论仍需
参数连续 DMRG 或显式反演对称化验证。

对应结果：

```text
data/near_zero_multistart/best_summary_b0.5_L60.csv
figures/near_zero_multistart_b0.5_L60.pdf
```

### 参数连续 DMRG

为消除多初态扫描中的扫掠方向偏置，从 `alpha=-0.15` 分别收敛
左、右边缘分支，并复用上一参数的 MPS 连续推进至
`alpha=-0.00625`。

连续扫描得到：

- 左右分支能量差仅为 `10^-12–10^-9`；
- 左分支与右分支反演后的磁化 RMS 小于 `7.5×10^-4`；
- 十格点边缘权重从 `alpha=-0.15` 的 `0.904` 平滑增加到
  `alpha=-0.00625` 的 `0.931`；
- 没有发现负侧内部的能量滞后、边缘权重塌缩或新边界。

这说明独立多初态扫描中的 `10^-4` 能量差确实是收敛路径误差。
在当前 `L=60` 精度下，负 `alpha` 区域一直保持边缘态，直到
特殊解耦点 `alpha=0`。

对应结果：

```text

```

## 当前结论

现有证据不支持把 `0.17≲alpha≲0.30` 命名为独立第四相。
更保守且更符合数据的解释是：

> 正 `alpha` 区域属于同一个以 `q=pi` 反铁磁关联为主的无隙相，
> `alpha≈0.17` 与 `alpha≈0.30` 是不同观测量对有限尺寸交叉的
> 响应尺度。

这一结论不是严格排除所有“两个无隙相”的可能性。若要提出两个
不同无隙相，必须找到量子数、对称性、拓扑指标或普适量的改变，
而不能只依赖两个响应峰。

对负 `alpha` 区域，长程弦序、深负 `alpha` 的稳定边缘磁化以及
切口纠缠谱低能簇共同支持 Haldane/SPT-like 解释。当前最强证据
位于 `alpha=-0.50`。参数连续 DMRG 进一步支持该区域延伸至
`alpha=0` 的负侧，并在特殊解耦点 `alpha=0` 与正侧分离。
