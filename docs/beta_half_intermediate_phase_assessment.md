# `beta=0.5` 候选中间相评估

## 问题

能量曲率在 `alpha≈0.17` 附近出现峰，纠缠熵响应在
`alpha≈0.30` 附近出现峰。需要判断两者之间是否存在独立第四相。

## 已完成判据

### 自旋能隙

对 `alpha=0.10–0.50` 的多个参数点进行 `L=40,60,80`
有限尺寸外推。所有正 `alpha` 点的自旋能隙均趋近于零。

这排除了区间 `0.17≲alpha≲0.30` 是普通有隙相的解释。

### 最近邻键关联

在 `L=100`、`beta=0.5` 下加密扫描

```text
alpha = 0.10, 0.14, 0.17, 0.20, 0.23,
        0.27, 0.30, 0.33, 0.40, 0.50
```

结果显示：

- `J1`、`J2` 和 `J3` 三类体区键关联均连续变化；
- `alpha≈0.17` 和 `alpha≈0.30` 附近没有跳变或键强度重排；
- 左右 `J1` 键差和左右 `J2` 键差约为 `10^-9–10^-7`；
- 没有发现自发二聚化或新的五聚体内部对称性破缺。

对应结果：

```text
data/bond_correlations/bulk_summary_b0.5_L100.csv
figures/bond_correlations_b0.5_L100.pdf
```

### 静态结构因子

在 `alpha=0.14,0.23,0.33` 三个代表点计算 `L=100`
静态自旋结构因子。三个点的主峰均位于

```text
q_peak / pi = 1.0000
```

峰高从 `3.390` 连续增加到 `4.065`，但没有主峰分裂、移动或
非公度化。因此候选区间两侧具有相同的主导反铁磁波矢。

对应结果：

```text
data/static_structure_factor/peak_summary_b0.5_L100.csv
figures/static_structure_factor_b0.5_L100.pdf
```

## 当前结论

现有证据不支持把 `0.17≲alpha≲0.30` 命名为独立第四相。
更保守且更符合数据的解释是：

> 正 `alpha` 区域属于同一个以 `q=pi` 反铁磁关联为主的无隙相，
> `alpha≈0.17` 与 `alpha≈0.30` 是不同观测量对有限尺寸交叉的
> 响应尺度。

这一结论不是严格排除所有“两个无隙相”的可能性。若要提出两个
不同无隙相，必须找到量子数、对称性、拓扑指标或普适量的改变，
而不能只依赖两个响应峰。

## 下一步

优先级如下：

1. 对 `alpha=0.14,0.23,0.33` 进行多尺寸实空间关联幂律拟合；
2. 用周期边界或更稳健的有限纠缠标度提取中心荷；
3. 检查纠缠谱量子数和简并结构；
4. 对负 `alpha` 区域计算边缘磁化，确认 Haldane/SPT 判据；
5. 完成上述判据前，相图中不要绘制第四相边界。
