# 五聚体链数值失败与相结构判断

更新时间：2026-08-11

## 一句话结论

当前失败主要是临界、近简并体系的 DMRG 末段收敛过慢，不是程序崩溃，也不代表“没有新相”。现有证据最支持两个临界相区：负 `alpha` 的弦/边缘活跃临界区与正 `alpha` 的 `q=pi` 无隙反铁磁区；`alpha=0` 是解析可知的解耦特殊线。负侧 `alpha≈-0.35~-0.25` 存在动量重构，但尚不足以命名第三相。

## 1. 失败原因分层

### 1.1 已修复的程序问题

最初 Stage A 输出的 `structure_factor_fullq.csv` 把换行写成了字面量 `\\n`。这属于文件格式错误，已经修复并通过后续 checksum、回传和独立 validator 验证。它与物理相结构无关。

### 1.2 后续失败是数值收敛门，不是程序异常

后续失败集中在 `alpha<0`、尤其接近 `alpha=0` 的大尺寸计算：

- Julia 正常退出，子任务返回码为 0；
- `stderr` 为空，未发现崩溃、内存溢出或文件损坏；
- 方差、截断误差、总 `Sz`、完整动量网格和 checksum 大多通过；
- 增加 sweeps 后，早期方差失败可由 `32 -> 64 -> 128` 补救；
- 多初态和参数连续结果表明，靠近 `alpha=0` 容易落入能量很接近的慢收敛分支。

因此这些失败反映的是临界体系的小能隙、长关联长度和低能近简并，而不是代码停止工作。

### 1.3 R16 为什么仍未通过最严格门

R16 对 `alpha=-0.05, beta=0.5, L=80` 使用三种初态和 256 sweeps。三条轨迹的最终能量变化为

```text
5.06e-8, 5.26e-8, 4.60e-8
```

均超过预设的严格门 `1e-8`，但低于实用校准门 `1e-7`。与此同时：

- 三初态基态能量展宽为 `9.87e-7`，未超过 `1e-6`；
- 三个自旋隙均为正，约 `8.92e-6~9.90e-6`；
- 方差、截断、`Sz` 和数据完整性门均通过；
- 三条轨迹给出相同的主导动量类别，没有分裂成互不相容的物理解。

这更像临界近简并流形中的缓慢末段优化，而不是相共存。R16 因而可作为相区校准点，但被明确禁止用于高精度相界拟合。

## 2. 为什么物理上预计至少有两个临界区域

模型是周期为五的自旋 `1/2` 最近邻海森堡链：胞内键序列为 `J2-J1-J1-J2`，胞间为 `J3`，其中 `alpha=J2/J1`、`beta=J3/J1`。

### 2.1 奇数自旋单胞约束

每个平移单胞含五个自旋 `1/2`，总自旋为半整数。保持 SU(2) 与单胞平移对称时，体系不能形成唯一、对称、完全有隙的基态。自然候选是无隙临界态，或者通过自发破缺产生简并。当前数据没有发现稳定二聚化或其他体对称破缺，因此无隙临界解释优先。

### 2.2 正 `alpha`：有效 `S=1/2` 临界链

孤立五聚体在正 `alpha` 区域以 `S=1/2` 双重态为最低局域自由度。正的胞间 `J3` 把这些有效自旋反铁磁耦合，得到以 `q=pi` 为主的无隙反铁磁链。现有自旋隙、幂律关联、结构因子和动力学数据相互一致。

### 2.3 深负 `alpha`：有效 `S≈3/2` 临界链

负 `J2` 使五聚体边缘键趋向铁磁对齐，孤立五聚体最低多重态变为 `S=3/2`。胞间正 `J3` 因而产生有效半整数反铁磁链，仍应无隙，但微观单胞形状因子把主导谱重移到约 `q≈3pi/5`。现有数据还显示慢幂律体关联、慢幂律弦关联和稳定边缘响应，因此工作名称是“弦/边缘活跃的非公度临界区”，而不是普通有隙 Haldane 相。

### 2.4 `alpha=0`：不是普通的数值相界

当 `alpha=0` 时，两条 `J2` 键严格消失，体系分解为胞内三聚体与胞间二聚体；剩余三聚体双重态造成宏观低能简并。该线是解析可知的奇异解耦线，也是两侧局域低能自由度重组的位置。它应在相图中单独画线，而不能由有限尺寸 crossing 代替。

## 3. 当前可能有几个相

### 保守结论：两个临界相区，加一条特殊线

1. `alpha<0`：弦/边缘活跃的临界区，深负侧主导动量约 `3pi/5`；
2. `alpha>0`：`q=pi` 无隙反铁磁临界区；
3. `alpha=0`：解耦与宏观简并特殊线，不计作有限面积相区；
4. `beta=0`：孤立五聚体边界，也不计作二维相区。

### 较激进但尚未证实：三个临界相区

在 `beta=0.5`，主导动量于 `alpha=-0.35~-0.25` 从约 `3pi/5` 重构到 `pi`，有限尺寸比值也在同一区间换号。如果后续六条 `beta` 切片上同时出现：

- 稳定的二维边界轨迹；
- `L=60/80` 的非解析或 crossing；
- 除 `q_peak` 外至少一个独立诊断的变化；

则负侧可能分成非公度临界相与共度临界相，总计三个相区。当前只有动量和有限尺寸候选信号，因而仍称 Lifshitz 重构或 crossover。

## 5. 何时可以命名新相

不要求每个校准点都达到不必要的极限精度，但相名必须满足物理证据完整性：

1. 计算通过方差、截断、守恒量、checksum 和独立 validator；
2. 候选边界在相邻尺寸上稳定，不能只是单尺寸峰位跳动；
3. 至少两个相互独立的诊断共同变化；
4. 边界在多个 `beta` 切片上构成连续轨迹；
5. 若只观察到主导动量移动而其他量平滑，则写作“动量重构/crossover”，不命名新相。

## 6. 当前可以写入文章的结论

- 五聚体的奇数单胞使正、负两侧都偏向半整数无隙临界物理，这解释了为何没有复现四聚体的普通有隙三相图。
- 正 `alpha` 区的内部响应峰没有形成可验收相界，现有结果支持同一个 `q=pi` 无隙区。
- 负 `alpha` 深处不是普通有隙 Haldane 相，而是兼具代数体关联、弦关联和边缘响应的临界候选态。
- `alpha=0` 是解析的解耦与低能自由度重组线。
- `alpha≈-0.3` 出现值得继续追踪的动量重构；它可能是 Lifshitz crossover，也可能在完整二维扫描后升级为第三个临界相边界。
