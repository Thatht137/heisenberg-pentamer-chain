# 投稿准备评估与短期计划

日期：2026-09-19。结论是“可写，但不建议立即投稿”；也不建议在证据边界不变的情况下无止境扫相。本评估只整理现有结果，不修改 `paper/`，不新增计算。

## 证据与主要缺口

- 正区已有 105 条记录和 3 个谱点的 `dt` 对照。
- 负区已有 Stage B：89 个 accepted、7 个 bounded；Stage C：29 个 accepted，但尚未得到共同相界。
- L=10、$\alpha=-0.1,-0.175$ 的 Krylov=8 保存态/增强诊断两点已独立通过总能量门；这只是局部校准，不是 L=80 收敛或低能谱热力学证据。
- 目前只有 8/12/16 晶胞尺寸，没有 chi series；$c_{\rm eff}$ 尚不能视为已确定的中央荷。
- $J_{\rm eff}=2\alpha^2/(9\beta)$ 的近 $\alpha=0$ 机制得到局部 ED 支持，但不是完整链验证；有限 $\alpha$ 的局部 oracle 偏差约为 36% 和 54%，不能把 leading 值当作真实 gap。

因此，当前最重要的技术补强不是继续扩大相图，而是补齐两点观测量收敛、完整链机制的定量对照，以及必要的少量负区谱分辨率检查。

## 期刊定位

现阶段不建议把“对称五聚体 + 暗模”表述为首次发现。已有 APS 工作研究对称五聚体的 INS 选择规则（[Phys. Rev. Lett. 107, 037205](https://journals.aps.org/prl/abstract/10.1103/PhysRevLett.107.037205)）；其几何和自旋设定不能直接等同本模型，需逐项比较后再写新颖性。

- 首选冲刺：PRB；其官方 scope 见 [APS PRB](https://journals.aps.org/prb/about)。
- 务实备选：JPCM 或 JMMM；JPCM 官方 scope 见 [IOP JPCM](https://publishingsupport.iopscience.iop.org/journals/journal-of-physics-condensed-matter/about-journal-physics-condensed-matter/)。
- 2025 年公开二手分区页面可作历史参考（PRB 大类 2 区、JPCM 4 区、JMMM 3 区），但不是 2026 官方核验，不能写成当前确定分区或 JCR 结论： [PRB 二手页](https://www.booksci.cn/journal/48701.htm)、[JPCM 二手页](https://www.ais.cn/journal/database/5036)、[JMMM 二手页](https://www.haoqikan.com/sci/03048853/)。

## 2–3 周行动与缓冲

1. 补两点关键观测量的收敛表，并明确误差预算与缺失项。
2. 对近零机制做完整链定量对照，保持“候选机制/局部 ED 支持”的措辞。
3. 仅在分辨率预算允许时补少量负区谱点；不把 $t_{\max}=30$ 未测试地复制到超低能区。
4. 据此完成最终稿、图表和证据索引；预留约 4 周缓冲。

上述计划不保证新相结论或录用；若收敛或机制对照不成立，应收窄主张并优先投 PRB/JPCM/JMMM 的合适栏目。
