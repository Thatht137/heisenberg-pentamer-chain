## 对方回复后的最短闭环

### 已采用方案：论文级 practical V2

1. 负区 `variance/site` 从 `1e-8` 放宽到 `5e-8`；历史回放表明该值释放唯一未决物理点，而 `1e-7` 不增加任何点。
2. checksum、总 `Sz`、截断、非负 gap、双初态和完整 full-q 文件门保持不变。
3. 新任务最高 64 sweeps；已有 128-sweep 结果保留但不再照此追加。
4. Stage B 只做粗 bracket；Stage C 仍以 64-sweep `L=60,80`、双诊断、`2 sigma` 和宽度 `<=0.025` 收尾。
5. 负区动力学在相数确定后，每个新增 bulk regime 一个代表点，只在最困难点做一次 `dt/dt/2`。

### 数据兼容方式

1. 不修改旧 manifest，也不把旧 `accepted=false` 原地改写。
2. V1 严格结果和 V2 实用结果使用不同 validator 与 acceptance 标签。
3. accepted-only 合并优先选择已经存在的高质量结果，不用较低 sweep 结果覆盖它。

### 仍然不放宽的物理门

1. 小负 gap 仍判失败，不能用放宽方差掩盖扇区能量倒置。
2. ratio 的 32/64 sweep 漂移最大约 0.139，因此最终相界不能只用 32 sweeps。
3. 若双诊断或最终尺寸对不闭合，负区仍降为探索结果。
