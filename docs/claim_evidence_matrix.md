# 结论—证据矩阵

本文件用于防止“先命名相、后寻找证据”。每次新增计算后更新状态。

状态：

- `待计算`：尚无结果；
- `初步`：单尺寸或单观测量支持；
- `较强`：多尺寸或多观测量一致；
- `可写`：已完成误差、边界和替代解释检查。

| 编号 | 暂定结论 | 必需证据 | 当前证据 | 状态 | 主要风险 |
|---|---|---|---|---|---|
| C1 | `alpha≈0` 是数值敏感区域 | 多初态、多扇区、能量方差、态重叠 | 绘图脚本人为屏蔽 `|alpha|≤0.1` | 初步 | 白带可能被误读为新相 |
| C2 | 区域 A 为四聚体/平庸相 | 键能周期、有限能隙、熵饱和、无保护边缘态 | 尚未形成完整证据链 | 待计算 | 仅凭强键示意图命名 |
| C3 | 区域 B 为 Haldane/SPT 相 | 长程弦序、边缘态、纠缠谱简并、虚空间投影表示 | 已有固定距离弦序热图 | 初步 | 半整数单胞与 LSM 约束 |
| C4 | 区域 C 为临界态 | `Δ→0`、CFT 纠缠标度、幂律关联、无隙 DSF | 已有少量中心熵拟合和 DSF | 初步 | 尺寸少、参数点少 |
| C5 | A 与 B 之间存在独立中间相 | 两条独立边界及中间区稳定特征 | 会议中观察到混合特征 | 待计算 | 可能只是有限尺寸交叉 |
| C6 | 弦序在某区域热力学极限为零 | `O_str(r,L)` 双重标度 | 当前仅有固定距离、有限尺寸数据 | 待计算 | 固定距离非零不代表长程序 |
| C7 | 存在拓扑边缘自旋 | OBC/PBC 低能谱、边缘磁化、尺寸稳定局域长度 | 尚无专门计算 | 待计算 | 普通边界束缚态伪装成拓扑态 |
| C8 | 临界激发可描述为稳定准粒子 | 峰位、线宽、尺寸稳定性、连续谱权重 | 已有 TEBD DSF 图 | 初步 | 宽峰不应称为准粒子 |

## 代表参数点

先固定 `beta=0.5`。参数值应根据现有相图和有限尺寸峰位重新确认，不要永久绑定以下占位符。

| 用途 | 参数点 | 选择原则 | 需要计算 |
|---|---|---|---|
| 区域 A 深处 | `[待定]` | 远离边界、键结构明显 | 键能、能隙、熵、纠缠谱、边缘磁化、DSF |
| 区域 B 深处 | `[待定]` | 弦序稳定、远离简并区 | 同上，重点检查 SPT 判据 |
| 区域 C 深处 | `[待定]` | 能隙最小、熵随尺寸增长 | 中心荷、幂律关联、DSF |
| `alpha≈0` | `alpha=±0.025, ±0.05, ±0.1` | 检查简并和收敛 | 多初态、多扇区、能量方差、态重叠 |
| 相边界两侧 | `[待定]` | 峰位外推附近 | 加密尺寸和参数扫描 |

## Results 段落模板

每段只做四件事：

1. 提出一个可检验问题；
2. 描述图中直接观察；
3. 给出有限尺寸或交叉验证；
4. 明确结论边界。

模板：

> To determine whether [问题], we compute [观测量] for [参数和尺寸]. Figure X shows [直接观察，不解释]. The feature [随尺寸如何变化] and is consistent with [第二证据]. These results support [有限结论], although [尚未排除的解释] requires [下一项分析].
