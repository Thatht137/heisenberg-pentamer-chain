# 正耦合区结论—证据矩阵

> 更新：2026-08-07
> 范围：`alpha>=0`、`beta>=0`；只记录能够进入当前五聚体论文的证据。

状态定义：

- `待计算`：缺少决定性数据。
- `初步`：只有单尺寸、单参数或单方法证据。
- `较强`：多尺寸或独立诊断一致，但仍有明确外推边界。
- `可写`：数值门槛、替代解释和结论边界均已记录。
