# 相图后续分析与操作方案

## 一、当前结论

已经完成的二维弦序热图只能用于寻找候选区域，暂时不能直接作为最终相图。

现有数据最明显的趋势是：

- `beta=0.5`、负 `alpha` 区域的弦序随尺寸减小后仍保持较大；
- 正 `alpha` 区域的弦序随尺寸快速下降；
- `alpha=0` 是模型局域结构发生改变的特殊点；
- 当前导数峰位置随尺寸明显漂移，尚不能可靠外推相边界；
- 当前中心熵数据存在强烈尺寸和切分位置效应。

因此下一阶段应遵循：

```text
观测量校准 → 一维切线判相 → 相边界标度 → 二维扩展 → 动力学解释
```

## 二、先修正两个基础问题

### 1. 弦序长度不统一

当前 `string_order_parameter` 使用最大可用距离，但固定丢弃三个位胞边界：

- `L=40` 时，两个端点只跨过一个胞间键；
- `L=60` 时，弦跨过五个位胞间距；
- `L=80` 时，弦跨过九个位胞间距；
- `L=100` 时，弦跨过十三个位胞间距。

这会导致 `L=40` 的结果更接近普通两点关联，而其他尺寸是长距离弦关联。它们不应直接放在同一条有限尺寸外推中。

应新增：

```julia
string_correlator_by_units(psi, sites, unit_i, unit_j)
string_order_vs_distance(psi, sites, N_units; ...)
```

每个参数点输出：

```text
alpha,beta,L,distance_units,O_str
```

分析时使用两种方案：

1. 固定相对距离，例如 `distance_units ≈ N_units/2`；
2. 对多个距离拟合常数、指数衰减或幂律衰减。

`L=40` 暂时不要用于长程弦序外推。

### 2. 中心切分受到五聚体键型振荡

五聚体链有五种不同的切键位置。不同 `L` 的 `L/2` 可能切在不同类型的键上，因此 `S(L/2)` 不一定可直接比较。

应输出沿链全部纠缠熵，并按 `bond mod 5` 分类。中心荷拟合时：

- 只比较相同键型；
- 或对一个五位点周期做平均；
- 排除边界附近数据；
- 使用开边界 CFT 形式拟合；
- 同时报告拟合残差和 bond dimension 收敛。

在完成上述修正前，不使用当前 `S(L/2)` 峰值宣布临界点。

## 三、阶段 0：数值可信度检查

### 目标

确认热图颜色来自基态，而不是不同初态、扇区或 bond dimension。

### 参数点

先固定 `beta=0.5`：

```text
alpha = -0.50, -0.25, -0.10, -0.05,
         +0.05, +0.10, +0.25, +0.50
L = 60, 80, 100
```

### 每个点至少比较

- Néel 初态；
- 随机 MPS 初态；
- 从相邻 `alpha` 基态热启动；
- `maxdim` 至少两档；
- 不同总 `S^z` 扇区；
- 基态能量；
- 能量方差；
- 最大截断误差；
- 最终 bond dimension；
- 不同结果的 MPS 重叠或局域观测量差异。

### 停止条件

只有当最低能量结果在不同初态下重复出现，且关键观测量差异小于预设误差，才进入判相阶段。

## 四、阶段 1：先判定 `beta=0.5` 切线

### 1. 代表区域

先使用中性命名：

| 区域 | 初始代表点 | 用途 |
|---|---:|---|
| 负 `alpha` 深处 | `alpha=-0.50` | 检查长程弦序和候选拓扑特征 |
| 负侧近特殊点 | `alpha=-0.05` | 检查接近局域简并时的尺度 |
| 正侧近特殊点 | `alpha=+0.05` | 与负侧比较 |
| 正 `alpha` 中部 | `alpha=+0.50` | 检查弦序衰减和临界性 |
| 均匀链基准 | `alpha=1,beta=1` | 校准中心荷、能隙和 DSF |

这些只是代表点，不是最终相标签。

### 2. 每个代表点计算

#### 静态局域量

- 每条键上的 `⟨S_i·S_j⟩`；
- `⟨S_i^z⟩`；
- 两点关联 `⟨S_i^z S_j^z⟩`；
- 总自旋或不同 `S^z` 扇区能量。

用途：判断是否存在四聚体、二聚体或其他局域键结构。

#### 非局域量

- `O_str(distance,L)`；
- 不同端点子格的弦序；
- 不同边界条件下的弦序。

用途：区分长程弦序、指数衰减和幂律衰减。

#### 能隙

- `Δ_s(L)=E_0(S^z=1)-E_0(S^z=0)`；
- 必要时计算同一扇区第一激发能；
- 使用多个外推形式比较稳定性。

用途：区分有隙相和无隙相。

#### 纠缠

- 沿链 `S(bond)`；
- Schmidt 值；
- 纠缠谱 `-2 ln λ`；
- 按切键类型分类。

用途：提取中心荷并寻找稳定简并。

#### 边缘

- 开边界固定总 `S^z=1`；
- 画 `⟨S_i^z⟩`；
- 比较多个 `L`；
- 比较开边界和周期边界低能谱。

用途：判断边缘磁化是否局域、是否随尺寸稳定。

### 3. 判相规则

#### 候选平庸有隙相

- 自旋能隙外推非零；
- 纠缠熵饱和；
- 弦序随距离衰减；
- 无稳定纠缠谱简并；
- 无保护边缘磁化；
- 键能呈明显局域团簇结构。

#### 候选 Haldane/SPT 相

- 体能隙外推非零；
- 弦序趋于非零；
- 纠缠谱简并在相内稳定；
- 开边界出现局域边缘自由度；
- 保护对称性明确。

#### 候选临界相

- 自旋能隙向零外推；
- 纠缠熵符合对数标度；
- 两点关联和弦关联呈幂律；
- DSF 低能谱随尺寸闭合。

#### 暂不分类

如果不同初态、键型或尺寸给出冲突结果，就标记为“数值不确定/交叉区”，不强行命名。

## 五、阶段 2：定位 `beta=0.5` 相边界

### 当前导数图的问题

现有 `plot_finite_size_dOstr.py`：

- 删除了 `|alpha|≤0.1`；
- 只在 `0.1<|alpha|<0.4` 内寻找峰；
- 对不同尺寸得到的峰位明显不稳定；
- 使用固定线性 `1/L` 外推，但尚未验证这种标度形式。

因此当前 `peak_alpha_vs_invL` 只能作为调试图，不能写成正式相边界。

### 新的边界定位方法

先在特殊点两侧分开扫描：

```text
alpha ∈ [-0.15,-0.01]
alpha ∈ [+0.01,+0.15]
step = 0.01
```

建议尺寸：

```text
L = 60, 80, 100, 120
```

同时观察：

- 基态能量一阶、二阶导数；
- 自旋能隙；
- 弦序距离标度；
- 纠缠熵或纠缠谱；
- 基态保真度或态重叠；
- 键能突变。

如果特征集中在 `alpha=0` 两侧并随尺寸靠近零，应优先考虑由耦合变号或局域简并控制的边界，而不是在 `alpha≈0.2` 强行拟合新边界。

## 六、阶段 3：回到二维相图

完成 `beta=0.5` 后，再增加四条切线：

```text
beta = 0.1, 0.3, 0.7, 1.0
```

每条切线先用较小尺寸定位候选边界，再只对边界附近做大尺寸计算。

二维相图最终应包含四层信息：

1. 候选相标签；
2. 相边界和误差带；
3. 数值不确定区；
4. 代表参数点。

不要仅根据热图颜色手动画边界。边界必须由至少两个独立观测量支持。

## 七、阶段 4：准粒子和 DSF

DSF 放在静态判相之后。

每个已确认区域选择一个深处参数点，相边界两侧各一个点：

```text
区域深处 A
边界左侧
边界附近
边界右侧
区域深处 B
```

分析：

- 最低峰位置；
- 软化动量；
- 峰宽；
- 谱重；
- 连续谱上下边界；
- 不同尺寸的谱峰漂移。

窄且尺寸稳定的峰可称为准粒子。宽连续谱应描述为多粒子连续谱或可能的分数化激发，不能只凭颜色命名。

## 十一、进入论文写作的最低条件

只有满足以下条件，才把某区域正式命名为一个相：

1. 至少两个独立观测量一致；
2. 有有限尺寸趋势；
3. 关键结果通过 bond dimension 检查；
4. 已排除初态和边界效应；
5. 相边界具有误差范围；
6. 对替代解释有明确讨论。
