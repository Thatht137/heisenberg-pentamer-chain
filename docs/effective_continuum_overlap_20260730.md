# 有效链连续谱与局域四重态重叠边界

> 状态：解析诊断，不是生产 DSF 结论。  
> 范围：`alpha=0.14,0.23,0.33`，正 `beta`。

## 核心结论

在当前经验受控的 `g=beta/Delta_1/2<=0.65` 范围内，孤立五聚体最低四重态
位于一阶有效 Heisenberg 链的两自旋子上边界之上。形式上的能量重叠只在
`g≈1.11–1.18` 出现，此时胞间耦合已经超过局域最低激发隙，一阶投影不再受控。

因此：

1. 弱耦合 `beta=0.05` 适合检验有效链连续谱和分离的局域四重态。
2. `beta=0.5` 三个代表点都远超当前有效理论受控区。
3. 不能把弱耦合解析边界直接叠加到 `beta=0.5` pilot 并据此命名谱支。
4. 强耦合下四重态是尖锐支、共振还是完全混入连续谱，必须由生产 CV 谱决定。

## 公式与归一化

有效哈密顿量使用自旋 `1/2` 算符：

```text
H_eff = J_eff sum_n T_n dot T_(n+1),
J_eff = beta c_1 c_5.
```

热力学极限反铁磁 Heisenberg 链的两自旋子边界为：

```text
omega_L(q) = pi J_eff / 2 |sin q|,
omega_U(q) = pi J_eff |sin(q/2)|.
```

在 `q=pi`，上边界为 `pi J_eff`。令其等于孤立单胞最低四重态隙
`Delta_3/2`，得到形式阈值：

```text
beta_embed = Delta_3/2 / [pi (J_eff/beta)].
```

这里使用 `S=sigma/2` 约定，不是 Pauli 矩阵约定。当前 `heisenberg-xxx`
oracle 卡确认了该约定、`v=pi/2` 和 des Cloizeaux--Pearson 下边界；其脚本不覆盖
两自旋子上边界。因此下边界可标记为 harness 依据，上边界仍只标记为标准
热力学两自旋子结果，不能写成由 oracle 脚本独立验证。
