## 4. 为什么弦序可能等于零

磁化强度与弦序不是同一个量。

- 无外场、保持自旋反演或时间反演对称时，局域磁化 `⟨S_i^z⟩` 可以严格为零；
- Haldane 型态中，局域磁化为零并不妨碍非局域弦序非零；
- 平庸短程纠缠态中，长距离弦关联通常衰减到零；
- 临界态中，有限距离弦关联可能非零，但随距离或系统尺寸幂律衰减；
- 简并点附近，DMRG 可能收敛到不同线性组合，使有限尺寸弦序对初态敏感；
- 端点选择、弦算符定义和边界效应也可能制造“假零”或“假非零”。

因此不能只画固定距离的 `O_str(alpha,beta)` 就宣布某相存在。至少需要研究：

```text
O_str(r, L)
```

即弦关联对端点距离 `r` 和系统尺寸 `L` 的依赖。

判据建议：

- `L→∞` 且 `r→∞` 后趋于非零常数：支持长程弦序；
- 随 `L` 或 `r` 指数衰减：支持有能隙平庸相；
- 随 `L` 或 `r` 幂律衰减：支持临界态；
- 对初态、端点或边界条件高度敏感：暂列为数值不确定。

## 5. 相的判定矩阵

### 5.1 候选四聚体/平庸相

优先检查：

- 四聚体内部强键上的 `⟨S_i·S_j⟩`；
- 不同键上的键能分布；
- 自旋能隙在 `L→∞` 后是否保持有限；
- 纠缠熵是否饱和；
- 纠缠谱是否缺少稳定的偶数简并；
- 开边界下是否没有受保护的边缘自旋。

“四聚体相”必须由局域键结构或相关函数周期性支持，不能仅根据示意图命名。

### 5.2 候选 Haldane/SPT 相

弦序非零只能作为线索，建议至少补充三类证据：

1. **边缘态**
   - 比较开边界和周期边界的低能谱；
   - 在固定总 `S^z=1` 或微弱边缘场下画 `⟨S_i^z⟩`；
   - 检查磁化是否局域在两端，以及局域长度是否随 `L` 稳定。
2. **纠缠谱**
   - 计算 Schmidt 值；
   - 检查低层纠缠谱是否存在对称性保护的简并；
   - 检查简并是否在候选相内部稳定、跨相边界消失。
3. **MPS 虚空间对称表示**
   - 在虚指标上提取自旋旋转、时间反演或反演对称的表示矩阵；
   - 检查其是否为非平庸投影表示；
   - 这是“虚参量表示”最接近严格 SPT 判据的含义。

注意：每个五聚体单元含有奇数个自旋 `1/2`。在平移和自旋旋转对称性保持时，LSM 型约束会影响“唯一、有能隙、对称基态”的可能性。因此使用“Haldane 相”前，必须明确有效自由度、保留的平移周期和可能的简并。

### 5.3 候选临界态

至少组合以下证据：

- 自旋能隙 `Δ(L)` 向零外推；
- 半链纠缠熵随 `ln L` 增长；
- 使用开边界 CFT 公式拟合中心荷；
- 自旋关联函数呈幂律；
- DSF 中出现随系统尺寸闭合的低能连续谱；
- 不同有限尺寸曲线出现可解释的标度坍缩。

不要只用四个尺寸对三个任意参数点做直线拟合后直接宣布中心荷。应在候选临界线附近密集取点，并报告拟合区间、残差和尺寸漂移。

### 5.4 “同时具有两相特性”的区域

这种现象通常有四种解释：

1. 有限尺寸交叉；
2. 相边界附近的相关长度大于系统尺寸；
3. DMRG 落入近简并态或亚稳态；
4. 真正的中间相或多临界区域。

判别顺序应为：

```text
收敛检查 → 尺寸漂移 → 能隙与纠缠标度 → 边界条件比较 → 再讨论新相
```

## 6. 准粒子与动力学分析

准粒子分析应围绕“低能激发是什么、是否稳定、在哪里软化”展开。

建议对每个代表相选择至少两个深处参数点，并在相边界两侧各加一个点：

1. 画 `S(q,ω)`；
2. 提取低能峰位 `ω_peak(q)`；
3. 估计谱线宽度和连续谱权重；
4. 检查最低激发在何处闭合；
5. 与静态自旋能隙外推比较；
6. 在临界区检查是否出现无隙连续谱而非孤立尖峰。

只有清晰、窄且随尺寸稳定的色散峰才适合称为准粒子。宽连续谱更可能对应多粒子激发或分数化激发。

## 7. 推荐的计算顺序

### 阶段 A：先验证观测量

1. 在可解析极限检查弦算符；
2. 增加 `O_str(r)`，不要只计算单一最大距离；
3. 比较随机初态、Néel 初态和不同总 `S^z` 扇区；
4. 保存 DMRG 能量方差、最大截断误差和最终 bond dimension；
5. 对 `alpha≈0` 单独做收敛表。

### 阶段 B：建立一条一维切线

先固定 `beta=0.5`，完成：

- `O_str(r,L)`；
- 键能和自旋关联；
- 自旋能隙；
- 半链纠缠熵；
- 纠缠谱；
- 边缘磁化；
- DSF 代表点。

一条切线证据闭环后，再扩展到二维相图。

### 阶段 C：确定相边界

- 用多个观测量独立定位边界；
- 对峰位做 `1/L` 或更合理的标度外推；
- 检查峰高、峰宽和拟合稳定性；
- 对疑似一级相变检查能量导数、滞后和态重叠。

### 阶段 D：扩展二维相图

二维图至少分为：

- 相标签图；
- 数值置信度图；
- 关键观测量图；
- 相边界及误差带。

## 8. 写作方法：Markdown 先行，LaTeX 汇总

不建议一开始就在 LaTeX 中连续写完整论文。推荐双层工作流：

### 8.1 Markdown 研究层

每天在 Markdown 中记录：

- 今天的问题；
- 使用的脚本和参数；
- 输出数据路径；
- 图的结论；
- 失败结果；
- 下一步；
- 可进入论文的句子。

Markdown 适合快速修改、会议记录和 Git diff。

### 8.2 LaTeX 论文层

当一个结论已经有稳定图和有限尺寸验证后，再写入 LaTeX。LaTeX 只保存：

- 已验证的方法；
- 已确认的结果；
- 图注；
- 讨论和限制；
- 正式参考文献。

推荐写作顺序：

```text
图和图注 → Results → Methods → Discussion → Introduction → Abstract → Title
```

不要从摘要开始，也不要先写长篇引言。
