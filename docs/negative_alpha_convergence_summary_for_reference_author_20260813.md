# 1×5 五聚体链负 α 区域：收敛分析

更新时间：2026-08-13  
项目状态：负 α 二维粗扫描已暂停；未继续启动新批次。  
参考论文：Li et al., *Spin order and spin excitation spectra of spin-1/2 tetramer chains*, npj Quantum Materials **11**, 37 (2026), DOI: 10.1038/s41535-026-00855-x。

## 1. 模型与数值问题

本研究比较四聚体链与五聚体链在基态相图、低能有效自由度和动力学响应上的差别。目前正耦合区域的计算比较稳定，但在负 α 区域做有限链 DMRG 二维扫描时，遇到了较明显的收敛和验收困难。

我们的模型取 `J1=1`、`J2=α`、`J3=β`。目前采用有限尺寸 OBC DMRG，主要尺寸为 `L=40,60`，校准点增加到 `L=80`；分别计算总 `Sz=0` 和 `Sz=1` 扇区，并比较 `center` 与 `ferro_j2` 两类初态。负区粗扫描使用 `maxdim=800 (L=40)`、`1000 (L=60)`、`cutoff=10^-11`，初始预算为 32 或 64 sweeps，失败后最多按 `32→64→128` 补算。我们自己的严格验收要求是：两个扇区、两个初态的 `variance/site≤10^-8`，最终截断误差不超过 `10^-9`，总 `Sz` 正确，并且 `E(Sz=1)-E(Sz=0)≥-10^-8`。

这里需要特别说明：并不是整个负 α 区域都不能收敛。`β=0.5` 的校准切片已经完成，16/16 个 `L=40,60` 控制点以及 8 个 `L=80` 校准点均通过验收；`β=0.05` 的 16 个粗网格点也已全部通过。困难主要表现为：32 sweeps 在多个新参数点上不能统一达到 `variance/site≤10^-8`，通常增加到 64 sweeps 后可以通过；靠近 `α=0` 的 `α=-0.025, β=0.05, L=60` 一度出现约 `10^-6–10^-5` 量级的负自旋隙和初态差异，增加到 128 sweeps 后才恢复为可接受结果。因此目前更像是低预算、初态依赖和近简并态造成的慢收敛，而不是程序普遍失效。

现在最卡的地方是二维粗扫描的效率和统一性。程序采用“首个失败即停止”的保守策略，所以几乎每进入一组新参数，就可能因某一个扇区或某一个初态的方差略高于门槛而中断，再增加 sweeps 重启。这样虽然能保留完整失败证据，但扫描推进很慢，也很难判断参考论文中 Fig. 3 的负 α 相图是否使用了同等级的验收标准。

我们从论文主文中查到的 DMRG 参数是 `L=64`、最大保留态 `m=800`、截断误差设置为 `10^-8`，收敛性说明指向 Supplementary Note Sec. G。主文没有给出 sweep 数、初态构造、噪声日程、能量方差、是否分别求 `Sz=0/1`、是否进行参数连续延拓，以及负 α 近简并区域如何选取最低能分支。因此仍需核对以下数值条件：

1. 四聚体 Fig. 3 负 α 区域采用的是有限 DMRG、iDMRG/VUMPS，还是其他方案？使用 OBC 还是 PBC？
2. 是否使用 U(1) 的总 `Sz` 守恒或 SU(2) 对称？不同相区是否使用了不同初态？
3. 扫描相邻参数时，是否将前一点的收敛 MPS 作为下一点初态，并从正反两个方向做 hysteresis/continuation 检查？
4. 每个点的 sweep 数、`maxdim` 增长方式、noise、Lanczos/Davidson 的 `niter` 与 eigensolver tolerance 分别是多少？
5. 文中所说“收敛”主要依据截断误差、相邻 sweep 能量差、能量方差，还是目标观测量随 `m` 的稳定性？是否要求 `variance/site≤10^-8`？
6. 负 α 区是否也分别计算 `Sz=0` 和 `Sz=1`？若 OBC 下出现接近零或轻微负的有限尺寸自旋隙，如何区分边缘态、近简并态和未充分收敛？
7. Fig. 3 的每个像素是否都是独立 DMRG 点？其 α、β 网格密度、插值方式和有限尺寸检查是什么？
8. Supplementary Note Sec. G 中用于证明负 α 结果收敛的原始数据与具体参数。

目前我们已经排除了几个简单的技术原因：各批次的 Julia 程序均正常结束，stderr 为空；远端和本地 checksum 一致；失败主要来自独立 validator 的科学门槛，而不是程序崩溃或文件损坏。服务器曾短时无法连接，但计算在断连期间继续运行，因此也不是本轮慢收敛的根本原因。

从物理上看，五聚体与四聚体不能简单一一对应。五聚体单胞含奇数个自旋 1/2，正 α 区单胞基态保留总自旋 1/2 双重态，并形成无隙有效反铁磁链；负 α 又引入铁磁胞内键，使低能总自旋扇区、边缘自由度和非公度关联发生竞争。我们在 `β=0.5` 看到主导动量从深负区的 `q_peak≈0.60π` 向近零负区的 `q_peak=π` 重构，候选区间约为 `-0.35<α<-0.25`，但目前还不能仅凭动量移动把它命名为新相。四聚体负 α 区的初态敏感性、近简并与 OBC 边缘态处理仍需对照。

## 2. 一句话概括当前问题

五聚体负 α 区并非完全不收敛，而是固定的 32-sweep 粗扫描在多个点无法同时满足“双初态 × 双扇区 × 方差/截断/能隙”的严格门槛；追加到 64 或 128 sweeps 多数可补救，但靠近 α=0 时存在近简并、初态敏感和有限 OBC 自旋隙易变号的问题，而参考四聚体论文没有在主文公开足够的收敛细节用于复现。

## 6. 可能的数值与物理原因

以下内容是当前工作解释，不是已经证明的结论。

### 6.1 铁磁键与反铁磁键竞争

负 α 使部分胞内键成为铁磁耦合，而其余胞内和胞间耦合仍为反铁磁。由此产生不同局域总自旋构型之间的竞争，能量景观中更容易出现相近的 MPS 局部极小值。`center` 与 `ferro_j2` 初态收敛速度不同与这一图像一致。

### 6.2 五聚体的奇数单胞效应

四聚体单胞可形成整数总自旋或单态；五聚体单胞含奇数个自旋 1/2，天然保留半整数低能自由度。因而 1×4 中适用的 singlet/Haldane 有隙图像不能直接移植到 1×5。特别是负 α 附近可能出现不同有效大自旋双重态之间的重排，使有限链 gap 更小、收敛更慢。

### 6.3 OBC 边缘态与扇区能量差

我们用 `E(Sz=1)-E(Sz=0)` 作为有限尺寸自旋隙。OBC 下，这个量可能优先反映边缘激发而非体能隙。当两个扇区的绝对能量只差 `10^-6–10^-5`，任一扇区少收敛一点就会使 gap 轻微变负。R7 的负 gap 在增加到 128 sweeps 后消失，支持“扇区收敛不平衡”而非物理负激发能的解释。

### 6.4 靠近 α=0 的局域简并与慢收敛

`α=0` 是特殊解耦线。靠近它时，铁磁键关联很弱，多个局域构型和边缘构型可能近简并。这里用固定乘积初态直接开始 DMRG，比从相邻已收敛参数做 adiabatic continuation 更容易卡在亚稳分支。

### 6.5 非公度关联与有限尺寸匹配

深负区观察到 `q_peak≈0.60π`，说明主导关联不是简单的 `q=π` Néel 模式。非公度波矢在有限 OBC 链上受到允许动量、中心窗口和边界钉扎影响；`L=40,60,80` 对同一波长的匹配不同，可能加重尺寸依赖和初态敏感。

### 6.6 当前验收可能过于“一刀切”

严格方差门适合建立高可信 source data，但不一定是绘制粗相图的唯一合理标准。一个点即使 `variance/site` 为几倍 `10^-8`，若其结构因子、弦关联和能量在 `m`/sweep 加倍后稳定，也可能足以作为探索级粗图数据。当前 pipeline 把“是否能用于精确相界”和“是否能用于粗相图”合并成同一个 pass/fail，导致推进效率过低。

## 10. 如果继续计算，建议的修复方向



1. 将粗相图与严格相界分成两级验收：粗图看观测量对 sweep/maxdim 的稳定性；边界点再要求当前完整严格门。
2. 改为从相邻已收敛点双向延拓 MPS，并保留独立乘积态作为交叉检查。
3. 对接近 α=0 和候选重构带的点预设 64 或 128 sweeps，不再从 32 开始反复失败。
4. 分别记录 `Sz=0` 与 `Sz=1` 的最后若干 sweep 能量和方差，识别是哪一扇区拖慢 gap。
5. 用 PBC、排除边缘的局域激发或更大尺寸复核轻微负 gap，区分边缘态与体激发。
6. 若条件允许，比较 SU(2)-MPS 或 iDMRG/VUMPS，以减少多重态分裂和 OBC 边缘影响。

## 11. 当前最稳妥的科学结论

- 正 α 区的五聚体链与四聚体链存在本质差异：奇数单胞留下有效 `S=1/2` 自由度，现有证据支持无隙 `c=1` 有效反铁磁链。
- 负 α 区已有可靠数据表明主导动量会随 α 发生重构；`β=0.5` 的候选区间约为 `[-0.35,-0.25]`。
- 目前没有足够证据宣布发现独立新相；动量峰移动也可能是同一临界相内部的 Lifshitz 型 crossover。
- 当前主要瓶颈是负区多初态、双扇区的统一收敛与相界证据，而不是模型、程序或数据完整性整体失效。
