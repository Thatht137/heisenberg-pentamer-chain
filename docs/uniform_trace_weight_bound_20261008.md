# 从谱矩到有限频率谱权重

日期：2026-10-08。上一轮推进了任意自旋精确二阶谱矩。本轮进一步回答：它能否排除“系统变大后权重趋于零”或“全部挤向零频”的解释？

## 定义及适用范围

仍是均匀最近邻 spin-s 有效链，偶数 N>=4、周期边界，`h=sum T_i dot T_(i+1)`，`R=(bY+uD_tilde)/sqrt(ell*N)`，仅改变实系数 u。要求 s>=1、b 非零。五聚体四重态为 s=3/2、ell=5。

本节的初态权重严格为 `1/(2s+1)^N`，即有效低能空间的均匀迹。不是原模型无限温度，也不是任意固定有限 `tau=T/Jeff` 的 Gibbs 态。极限顺序是先在固定 N 控制弱耦合、取有效均匀占据，再研究 N 增大。不给原模型有限 beta 的链长一致展开作保证。

定义 `C_tr(>nu)` 为无量纲频率 `epsilon_f-epsilon_i>nu` 的正频率积分，`M_(2k)` 为正负频率全部积分矩。M0 包含等能块。

## 推导

令 c=s(s+1)。局域自旋与四极矩迹正交给出

\[
M_0=\ell^{-1}[cu^2/3+b^2c^2(4c-3)/27].
\]

结合已证明的 M2，得到 `M2 >= (3c/2) M0`。把 b、u 按 M0 系数归一化，差的二次型对角元是 `(61c-42)/30`、`7c/6`，行列式是 `c(107c-54)/180`，对 c>=2 严格正；这不是有限点拟合。

将一阶对易子写为

\[
[h,R]=(\ell N)^{-1/2}\sum_i(-1)^iB_i,
\quad B_i=bC_{X,i}+uC_{D,i}+bZ_{i,i+1,i+2}.
\]

不同两点、三点支撑正交，所以归一化局域迹满足 `||B_i||_2^2=ell*M2`。只有与三个点相接的四个哈密顿量键参与 `[h,B_i]`。单键算符范数为 c，因此 `||[h,B_i]||_2 <= 8c ||B_i||_2`。

这个二阶对易子只支撑于从 i-1 至 i+3 的五点区间，且总迹为零。不相交支撑的内积为零；每个区间最多与九个平移区间相交，包括自身。N=4、6、8 时仅有 N 个。因此

\[
M_4\le576c^2M_2.
\]

将频率分成 `|omega|<=nu` 和其余部分；低频对 M2 的贡献不超过 `nu^2 M0`。对高频部分用 Cauchy--Schwarz，利用均匀迹的正负频率对称性：

\[
C_{\rm tr}(>\nu)\ge\frac{[M_2-\nu^2M_0]_+^2}{2M_4}.
\]

取 `nu=sqrt(3c/4)`，得到对全部 u 和偶数 N>=4 均成立的结果：

\[
C_{\rm tr}(>\sqrt{3c/4})\ge\frac{M_2}{4608c^2}
\ge\frac{b^2(4c-3)(86c-27)}{3732480\ell}>0.
\]

四重态五聚体为 `C_tr(>sqrt(45)/4) >= 197*b^2/1036800`；全正频率积分另有较强界 `C_tr(>0) >=197*b^2/259200`。频率单位为 Jeff，阈值约 1.677 Jeff，并非人为删掉准弹性数据后的拟合。
