# 五聚体链完整相图计算与验收标准

更新时间：2026-08-09

## 1. 研究范围

- 模型：自旋 `1/2` 五聚体 Heisenberg 链，`J1=1`、`J2=alpha`、`J3=beta`。
- 相图范围：`-1 <= alpha <= 1`、`0 <= beta <= 1`。
- 边界条件：有限链 DMRG 使用 OBC；必要的体能隙复核另行使用 PBC 或排除边缘多重态。
- 对称扇区：至少计算总 `Sz=0` 和 `Sz=1`。
- 参考论文 Fig.3 的完整参数区域纳入；Fig.9 仍排除。
- 不修改 `paper/`，阶段结论仅进入研究报告与结果目录。

`alpha=0` 与 `beta=0` 是解析上可识别的解耦边界。它们单独展示，不作为二维内部 crossing 点强行拟合。

## 2. 现有数据的使用等级

### 探索级

`data/phase_diagram_80x60_hires.csv` 覆盖 `alpha != 0` 的 80×60 网格，可用于绘制背景热图和选择候选切片。该文件存在重复行，且缺少逐点方差、截断误差、实际键维和独立 manifest，因此不能单独支持相边界或相名。

### 严格级

正 `alpha` 区已有 L=40、60、80 的多初态、双扇区数据。只有逐 cell checksum、manifest 和科学验收均通过的记录可复用。负 `alpha` 区必须使用独立 runner、独立 run id 和独立 provenance，不能改写正区结果。

## 3. 分阶段扫描

### 阶段 A：负区校准切片

```text
beta  = 0.50
alpha = -1.00, -0.50, -0.35, -0.25, -0.125, -0.05, -0.025
L     = 40, 60
```

目标：验证负区多初态收敛、主导动量 `q_peak`、主峰 correlation ratio、弦关联和边缘诊断。阶段 A 全部通过后才进入二维扩展。

### 阶段 B：二维粗网格

```text
beta  = 0.05, 0.10, 0.25, 0.50, 0.75, 0.90, 1.00
alpha = -1.00, -0.50, -0.35, -0.25, -0.125, -0.05, -0.025
L     = 40, 60
```

阶段 A 的已验收 cell 直接复用。已有正区严格数据直接合并，不重复计算。

### 阶段 C：相界细化与尺寸提升

- 只细化具有显著 bracket、动量重分配或独立诊断冲突的区间。
- `alpha` 细化目标宽度不超过 `0.025`。
- 最终判定必须由相邻尺寸 `L=60,80` 支持。
- 无候选边界的区域只提升代表点，不做无界加密。

## 4. 每个 cell 的计算内容

- 两个独立初态或参数连续低能分支；负区近 `alpha=0` 必须比较最低能量分支。
- `Sz=0`、`Sz=1` 的能量、方差、截断误差、实际最大键维和 sweep 历史。
- 中心窗口 connected `S(q)`，覆盖 `0 <= q <= pi`，记录 `q_peak/pi`、`S(q_peak)` 和主峰 correlation ratio。
- `q=pi` correlation ratio 仅作正区对照，负区不以它作为唯一判据。
- 弦关联随位胞距离的 profile。
- 五类键关联、中心多切口 Schmidt 谱和边缘磁化诊断。

## 5. 单 cell 科学验收

以下条件全部满足才记为 accepted：

- Julia 正常终态，所有请求 sweep 完成；
- `variance/site <= 1e-8`，两个扇区分别检查；
- 最终截断误差 `<= 1e-9`，两个扇区分别检查；
- `abs(Sz_0) <= 1e-8`，`abs(Sz_1-1) <= 1e-8`；
- 所有主观测量有限，所需 CSV 与 manifest 齐全；
- 多初态最低能量分支一致，或较高能假收敛分支被明确排除；
- 主观测量误差超过预设精度时只能用于粗图，不能用于边界拟合。

失败 cell 保留原目录和证据。仅允许按预先声明的 `32 -> 64 -> 128 sweeps` 上限重试，不降低阈值。

## 6. 相边界与相名规则

### 有限尺寸边界

- correlation-ratio crossing 使用 `2 sigma` 显著性。
- 最终 bracket 宽度 `<= 0.025`，并由 `L=60,80` 支持。
- scheduler 或进程成功不等于科学验收成功。

### 相名

至少两个独立观测量和有限尺寸趋势一致，才能命名相：

- 临界相：体关联幂律、纠缠熵对数标度、体激发闭合或低能 DSF 支持。
- SPT/Haldane-like：体能隙、非零长程弦序、稳定纠缠谱简并和边缘自由度共同支持。
- 动量重分配：仅 `q_peak` 改变而能量、指数和纠缠无非解析特征时，标记为 crossover 或候选 Lifshitz 线，不命名为新相。
- 诊断冲突时标记 `NotEvaluable`，不手动画边界。

`alpha=0` 和 `beta=0` 作为解析特殊边界分别标注；是否属于常规热力学相边界由数值证据另行说明。

## 7. 服务器执行与回传

- 本地保存相图 policy、controller state、observations 和报告；远端只接收计算入口、run spec 和必要依赖。
- 每批启动前核对目标账户、Julia/Manifest/源码 hash、磁盘和现有重任务。
- 一个 heavy cell 内的并发量由服务器核心数和内存探针决定，不盲目超配 Julia。
- 每个 batch 写入 PID、锁、progress、status、stdout、stderr 和条件 ETA。
- 远端终态后先执行 checksum；结果非覆盖回传到新的本地目录，再做本地 checksum 和独立 validator。
- 服务器断网时不在远端下载依赖；必须由本地上传，成功后清理仅用于传输的本地临时包。

## 8. 完成定义

完整相图只有在以下项目全部完成后才可宣布完成：

1. 探索背景图完成去重并保留来源说明；
2. 七条 `beta` 切片的负区严格数据通过验收；
3. 所有候选内部边界达到最终尺寸与宽度门槛，或被严格标记为无显著 bracket；
4. `alpha=0`、`beta=0` 的解析边界单独说明；
5. 相区名称满足双诊断与有限尺寸规则；
6. CSV、SVG、PDF、PNG、TIFF、source manifest 和 HTML 报告同步生成；
7. 图中探索级、严格级和未决区域可清楚区分。
