# 五聚体链论文图表计划

参考文献：Li et al., npj Quantum Materials (2026), "Spin order and spin excitation spectra of spin-1/2 tetramer chains"

本文档对照参考文献的 Fig. 1–9，逐一说明其物理含义，以及五聚体版本需要计算/绘制的内容。

> **范围约束：** Li 等研究的是偶数自旋单胞的四聚体链。本文档只借用其
> “单胞能级—弦关联—纠缠—DSF”的证据组织方式，不预设五聚体也具有相同的
> 三相结构、弦算符端点、解禁闭机制或 `triplon/quinton` 激发命名。五聚体的
> 相与激发必须由本模型的有限尺寸标度、有效低能自由度和谱函数独立确定。

## Fig. 3 — 弦序参量相图（核心图）

**文献内容：**
- (a) O_str(α, β) 二维热力图，标注 Zone I（tetramer phase）、Zone II（Haldane phase）、Zone III（相变边界/解禁闭自旋子态）
- (b) O_str vs β 曲线（固定 α = −1.0, −0.5, 0.1, 0.5, 1.0）
- (c) O_str vs α 曲线（固定 β = 0.1, 0.5, 1.0）
- (d) dO_str/dα 导数（定位相变点）
- (e) 三种基态的示意图

**物理意义：** 在 Li 等的四聚体模型中，弦序与隐藏 Z₂×Z₂ 结构用于区分
平庸四聚体相和 Haldane-like 相。对五聚体链，`O_str≠0` 只能作为候选
SPT-like 区域的证据之一，必须与距离/尺寸标度、边缘响应和纠缠结构联合判断；
导数峰值也只能先视为响应尺度，不能单独定义相变。

**五聚体版本需要：**
- [x] 已有：11×10 粗网格的 O_str(α, β) 数据和热力图
- [ ] 加密网格：α 至少 41 点（步长 0.05），β 至少 20 点（步长 0.05），避开 α=0 奇异点
- [ ] 画 1D 切片曲线 O_str vs β（固定 α）和 O_str vs α（固定 β）
- [ ] 计算 dO_str/dα 数值导数，定位相变点
- [ ] 确定五聚体链的相边界位置，与四聚体对比
- [ ] 仅在独立证据闭合后标注相区；此前使用“候选区域”或“不确定区域”

**计算量：** 中等。41×20=820 个 DMRG 计算（N_units=12, maxdim=400），每个约 1-3 分钟。总计约 15-40 小时（可并行）。

## Fig. 5 — 激发态示意图

**文献内容：** 各种集体激发的图示：triplon（单态→三重态）、quinton（单态→五重态）、spinon（自旋子）在链上的传播方式。

**物理意义：** 直观展示不同相中支持的元激发类型。四聚体链中：

- Haldane phase → triplon 激发（从二聚体单态激发）

## Fig. 6 — 动力学结构因子 S^zz(q,ω) 系统扫描

**文献内容：** 8 幅 DSF 谱：α=1.0 和 α=−1.0 各 4 幅（β=1.0, 0.7, 0.4, 0.1），展示从 Haldane 相到平庸相的激发谱演化。

**物理意义：** DSF 直接对应中子散射实验可测量的谱。Li 等的四聚体结果展示：
- 有能隙的 triplon 带（平坦，高能）
- 有能隙的 spinon 连续谱（色散，低能）
- 能隙随 β 减小而关闭的过程

这些激发名称不能直接移植到五聚体谱；五聚体中先描述峰位、能隙、线宽和
连续谱边界，再结合单胞多重态与有效模型命名。

**五聚体版本需要：**
- [x] 已有：`scripts/04_dsf.jl` 实现了修正向量法 DSF 计算
- [ ] 系统扫描：选取 α=1.0, −1.0（或其他代表性值），β=1.0, 0.7, 0.4, 0.1
- [ ] 每组参数计算完整的 S^zz(q,ω)，q∈[0,2π]，ω 覆盖到最高激发能
- [ ] 使用文献的分段色标方案（低强度线性映射 + 高强度对数映射）
- [ ] 对比四聚体结果，识别五聚体特有的激发带

**计算量：** 大。每组参数需要 ~50-100 个 (q,ω) 点的修正向量求解。8 组参数，总计约 400-800 个 linsolve。建议 N_units=16, maxdim=400-600。预计每组 2-6 小时（8 线程并行），总计 16-48 小时。

## Fig. 7 — 跨相变的 DSF 演化

**文献内容：** 固定 α=−142/240（CuInVO₅ 参数），β 从 0.04 增大到 0.16，穿越相变点 β_c≈0.079。展示从平庸相到 Haldane 相的谱学信号变化。

**物理意义：** 展示相变点处的特征：
- β < β_c：有能隙的 triplon 带
- β ≈ β_c：无能隙的 two-spinon 连续谱（des Cloizeaux-Pearson 边界）
- β > β_c：Haldane 能隙重新打开，quinton 激发出现

**五聚体版本需要：**
- [ ] 先从 Fig. 3 确定五聚体的相变点 (α_0, β_c)
- [ ] 选取穿越相变的参数路径，计算 4 组 DSF

**计算量：** 与 Fig. 6 类似，4 组 DSF，约 8-24 小时。

## 与四聚体论文的关键对比点

五聚体相对于四聚体的新物理：
1. 单胞基态是 S=1/2（doublet），而非 S=0（singlet）→ 链的有效描述不同
2. 可能存在四聚体中没有的激发类型（如从 S=1/2 到 S=5/2 的 ΔS=2 跃迁）
3. α=0 的退化结构不同（三聚体+2自由自旋 vs 二聚体+2自由自旋）
4. 相边界位置和相变性质可能不同
5. 奇数格点单胞 → 总自旋为半整数，Kramers 简并保证
