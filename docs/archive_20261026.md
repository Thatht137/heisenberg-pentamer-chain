## 完整资料下载

进入 [收尾归档 Release](https://github.com/Thatht137/heisenberg-pentamer-chain/releases/tag/archive-2026-10-26)，下载全部 `pentamer-*-20261026.zip`，解压到同一目录。各包保留项目原相对路径。

| 分包 | 内容 |
|---|---|
| `code` | 源代码、计算脚本、测试、Julia 环境文件 |
| `documents` | 论文源文件及 PDF、图源索引、报告、原有投稿压缩包 |
| `data` | `data/` 和 `results/`，包括计算检查点、数值结果与日志 |
| `figures` | 图表及各格式导出 |
| `history` | `_archive/` 下的历史资料 |
| `references` | 本地参考资料及其代码 |

文件清单见 [manifest.csv](archive_20261026/manifest.csv)，包含相对路径、字节数、SHA-256 和所属分包。分包校验值见 [SHA256SUMS.txt](archive_20261026/SHA256SUMS.txt)，统计见 [summary.json](archive_20261026/summary.json)。`sha256` 对应归档内容，`source_sha256` 对应打包时的本地文件。

本机软件环境、依赖缓存、临时逐页渲染、Git 内部文件、凭据诊断日志和本地执行约束不放入资料包；逐项记录在 [excluded.csv](archive_20261026/excluded.csv)。Git 提交历史在仓库中保留。

## 环境与运行入口

- Julia 依赖：项目根目录 `Project.toml`、`Manifest.toml`。
- 基础检查：`julia --project=. test/runtests.jl`。
- 计算与绘图入口：`scripts/`；程序模块：`src/`。
- 当前稿构建：`paper_prb/rank_candidate/build.ps1`。
- 前阶段稿构建：`paper_prb/build.ps1`。
- 数据与图表来源：各结果目录的运行记录及稿件图源索引。

作者、单位、邮箱和资助字段沿用稿件现有占位，具体待办见各稿件目录的 README。
