## 2. DMRG 基准验证（scripts/02_dmrg_chain.jl）

### 2.1 近似孤立极限（beta ≈ 0）

- ED 参考：E_gs/unit = -1.92789，total = -7.71155（4 个单元）
- DMRG 结果：E_gs = -7.71176（maxdim=100, 6 sweeps）
- 相对误差：~0.03%

误差来源包括 beta=0.001 引入的微弱胞间耦合和有限 bond dimension 截断。

### 2.2 均匀 Heisenberg 链（alpha=1, beta=1）

- DMRG：E/site = -0.440050（L=60, maxdim=200）
- Bethe ansatz 热力学极限：E/site = -0.443147
- 偏差：~0.7%

该对比包含有限尺寸效应（L=60 开边界）和 maxdim=200 的截断影响。

### 2.3 Sz 分布验证

alpha=1, beta=0.5 时，计算所得基态的局域 ⟨Sz_j⟩ 均在 10⁻⁶ 量级。

## 3. 动力学结构因子小体系检验（scripts/04_dsf.jl）

小体系参数：N_units=6, L=30, eta=0.1, 5×11 网格。

### 检验项

1. **非负性**：S(q,ω) ≥ 0（最小值 ~10⁻³⁸，仅浮点误差）
2. **q=0 和 q=2π 处谱权重为零**：S^z 总量守恒的必然结果
3. **反演对称性**：S(π/2, ω) = S(3π/2, ω)，最大偏差 ~4×10⁻⁵
4. **q=π 处低能峰**：S(π, ω≈0) = 1.32

## 4. 相图小体系检验（scripts/03_phase_diagram.jl）

小体系参数：N_units=4（小体系检验），11×10 网格。

### 记录结果

- margin 自适应修复后的这组计算无运行时错误
- 数值无 NaN/Inf
- alpha=0 时 O_str=0.25 符合孤立 dimer 的解析值 -⟨Sz_i Sz_j⟩ = 1/4

### 已知局限

小体系（N_units=4）下 margin 被自动缩减，实际测量的是短程关联而非长程弦序参量。采用 N_units≥12、margin=3 可使 string 区间跨越多个单元。
