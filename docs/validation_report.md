## 2. DMRG 基准验证（scripts/02_dmrg_chain.jl）

### 2.1 近似孤立极限（beta ≈ 0）

- ED 参考：E_gs/unit = -1.92789，total = -7.71155（4 个单元）
- DMRG 结果：E_gs = -7.71176（maxdim=100, 6 sweeps）
- 相对误差：~0.03%

误差来源：beta=0.001 引入的微弱胞间耦合 + 有限 bond dimension 截断。结果合理。

### 2.2 均匀 Heisenberg 链（alpha=1, beta=1）

- DMRG：E/site = -0.440050（L=60, maxdim=200）
- Bethe ansatz 热力学极限：E/site = -0.443147
- 偏差：~0.7%

有限尺寸效应（L=60 开边界）和 maxdim=200 的截断共同贡献了这个偏差。对于验证目的，精度足够。

### 2.3 Sz 分布验证

alpha=1, beta=0.5 基态的局域 ⟨Sz_j⟩ 均在 10⁻⁶ 量级，确认：
- 基态处于 Sz=0 扇区（singlet）
- 无自发对称性破缺
- DMRG 收敛良好

## 3. 动力学结构因子试跑（scripts/04_dsf.jl）

小体系参数：N_units=6, L=30, eta=0.1, 5×11 网格。

### 验证通过的物理约束

1. **非负性**：S(q,ω) ≥ 0（最小值 ~10⁻³⁸，仅浮点误差）
2. **q=0 和 q=2π 处谱权重为零**：S^z 总量守恒的必然结果
3. **反演对称性**：S(π/2, ω) = S(3π/2, ω)，最大偏差 ~4×10⁻⁵
4. **q=π 处低能峰**：S(π, ω≈0) = 1.32，符合近无能隙反铁磁链的自旋子连续谱特征

### 关于 S(π, ω=0) 峰的说明

此峰不是数值伪迹。代码使用 S^z_q 算符，在 Sz=0 singlet 基态中 ⟨ψ₀|S^z_q|ψ₀⟩ = 0（对所有 q），因此不存在弹性散射贡献。该峰来自 q=π 处自旋子激发的低能连续谱被 η=0.1 展宽后堆积在 ω≈0 附近，是正确的物理行为。
