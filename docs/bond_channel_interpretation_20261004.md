# 相邻自旋通道的解析解释

## 要回答的问题

新稿的 Q*T 复合矢量为什么不同于一个普通自旋探针？仅说“允许秩二张量”不够直观。这里把它改写成相邻有效自旋的总自旋跃迁通道，不引入新模型或实验假设。

取两相邻有效自旋 s，定义 h_ij = T_i dot T_j，D_ij = T_i^z - T_j^z，及

X_ij = sum_mu (Q_i^{z mu} T_j^mu - T_i^mu Q_j^{z mu}).

由四极矩的定义直接展开可得严格算符恒等式：

X_ij = {h_ij,D_ij}/2 + s(s+1) D_ij/3.

两站点的总自旋 J 子空间中，h_ij 的本征值为 [J(J+1)-2s(s+1)]/2。D_ij 是交换奇的矢量，所以只连接 J 与 J-1；相同 J 被交换奇性排除，其他差值被矢量选择定则排除。于是

P_J X_ij P_{J-1} = [J^2/2 - 2s(s+1)/3] P_J D_ij P_{J-1}.

这是标准角动量代数在当前探针上的具体应用，不宣称新选择定则。

## 两个局域自旋的差别

- s=1/2 只有 J=1 <-> 0，系数为零，复合项恒等消失。
- s=3/2 有 J=1 <-> 0、2 <-> 1、3 <-> 2 三个通道，复合项相对 D_ij 的系数依次为 -2、-1/2、2。

在当前 q=pi 精确根，单条有向键的一阶探针对比为 -a D_ij + b X_ij，其中 a=-0.1212357695425，b=0.1236117648015。三个通道的实际系数依次为 -0.1259877600604、0.0594298871418、0.3684592991455。重调 alpha 只加上一个与 D_ij 成比例的共同项，不能同时使这三个不同的算符系数都为零。

这里的“不能同时为零”是键算符层面的判断，**不是**每个链基态必然具有非零残余谱权重的证明。不同键的振幅还会干涉，且基态不必激活所有通道。此前 N=4 PBC 的零残余继续成立；整条链是否留下谱权重仍要用基态源向量的 Gram 残余检查。
