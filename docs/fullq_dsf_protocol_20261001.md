# 完整动量谱与反演对称性

## 定义

以 J1=1、格点间距=1 为单位，L=40、开放边界、J3=0.5，分别计算 J2=+0.5 和 -0.5。

动量算符为 O(q)=L^(-1/2) sum_j exp(i q j) Sz_j。先减去基态期望，得到 b(q)=[O(q)-<O(q)>]|0>。
计算 C(q,t)=<b(q)|exp[-i(H-E0)t]|b(q)>，包含真实 t=0。

S(q,omega)=Re integral_0^T dt exp(i omega t) C(q,t) [1-t/T] / pi。

三角时间窗是显式的有限时间谱估计，不是对热图做平滑。其单极点展宽核为
T/(2 pi) sinc²[(omega-gap)T/(2 pi)]，其中 sinc(x)=sin(pi x)/(pi x)。
FWHM 约为 5.56623/T；T=60 时约为 0.09277 J1。
频率采样 0.005 J1 不等于物理分辨率。小于展宽的低能峰间距不能凭采样密度认定已分开。

## 对称性

本模型没有复数手性相互作用，H 在 Sz 基底为实矩阵。实基态与实本征态给出
<n|O(2pi-q)|0>=<n|O(q)|0>*，因此各跃迁的绝对平方权重相同。
此外，偶数个完整五聚体的开放链满足键反演 J_j=J_(L-j)。
完整自相关的物理谱应满足 S(q,omega)=S(2pi-q,omega)。

单个源格点的关联 C_j,j0 不等于完整动量自相关。源点反演后通常变成另一格点，
对其单边复数傅里叶变换取实部还会混入动量奇分量，不能把这种不对称当作物理结论。
旧图存在该问题，不能作为完整 DSF 的发表图，也不能通过镜像平均补救。

新实现独立演化全部 41 个动量。绘图不做镜像平均，不做高斯平滑，不插值动量，
不裁剪源数据。使用奇键半步、偶键整步、奇键半步的 Strang 分层；偶数长度下每层保持反演。
MPS 截断仍有有限误差，因此需要独立检验 q 与 2pi-q，而不是预先假定数值结果精确对称。
范数监测使用 ITensorMPS 的规范中心范数，非规范态由库自动回退到完整收缩。
每 200 步及末步额外用完整收缩核对，相对差须 <1e-8；关联函数仍在每个 dt 真实计算，没有抽稀。

q=0、2pi 对应总 Sz。Sz=0 基态的完整连通谱应为零；旧单点源图中亮的端点不能照搬。

## 数值检查

初始预算：DMRG maxdim=256、20 sweeps、cutoff=1e-12；TEBD maxdim=192、dt=0.05、T=60、cutoff=1e-10。
不是预先认定的收敛值。按实测范数、负谱、静态权重与谱漂移决定是否提高预算。
负参数点的初始 20 轮方差为 1.90e-8/格点，已停止该基态的动力学扫描，保留为无效起步计算。
新增基态前置检查：方差须 <=1e-10/格点；未达标时从现态追加 20 轮，局部 Krylov 维数 8、最多 4 次重启。
最多追加三组；仍未达标即停止。更换基态须新建结果目录，不复用旧的动力学断点。

小体系基准为 L=10、Sz=0 的完整精确对角化，Hilbert 空间维数 252。
两个参数点的精确谱都独立检查反演；额外以相同离散积分比较 TEBD 关联函数与 ED。
对 L=40，选 q/pi=0.4、0.7、1.0、1.3、1.6，使用 dt=0.025、maxdim=256 做联合对照。
该对照测试两项改进的联合影响，不分别归因于步长与键维数。

内部验收阈值：基态方差/格点 <1e-8；反演相对 RMS <0.002；最大范数漂移 <0.01；
静态源权重相对差异 <1e-7；负谱绝对权重比例 <0.001。
联合对照要求谱相对 RMS <0.03、低能谱与权重差异 <0.05、主峰漂移 <=0.015 J1。
这些是本次图像的内部数值标准，不是热力学极限或独立峰可分辨性的证明。

## 低能参照

另用分扇区 DMRG 计算 L=40 开放链的 E(Sz=1)-E(Sz=0)。
两档联合预算为 maxdim=512/cutoff=1e-12 和 maxdim=768/cutoff=1e-13，各态方差须 <=1e-10/格点。
J2=+0.5 的有限链自旋隙为 0.05562244068 J1，预算漂移 6.44e-12 J1；
J2=-0.5 为 0.001092444472 J1，预算漂移 2.03e-13 J1。
二者均小于 T=60 的时间窗 FWHM；仅缩小频率网格不能解决此展宽限制。
这些是有限链能级差，可能受边界态影响，不是热力学极限体相能隙。
预算漂移不是严格误差界。原始扇区态和能量保存在 spin_gap_L40，脚本为 compute_spin_gap_20261001.jl。

- 计算脚本：scripts/compute_fullq_dsf.jl。
- ED 基准：scripts/check_fullq_dsf_ed.py。
- 运行中断点检查：scripts/inspect_fullq_dsf.jl。
- 验收与截图风格绘图：scripts/audit_fullq_dsf.py。
- 数据：results/fullq_dsf_20261001。
- 最终图和验收报告：figures/fullq_dsf_20261001。

PNG/PDF/SVG 使用实际 q、omega 坐标和原始像素网格，统一线性色标。
超过显示 vmax 的值只显示颜色饱和，CSV 中的数值不变；饱和比例记录在 qa.json。
若验收失败，文件名包含 diagnostic_only；只通过初始检查的图标为 symmetry_checked_draft。
仅在联合对照也通过后生成 accepted 文件名，不将未收敛图冒充最终结果。

每个动量独立保存完整关联函数和范数。每 200 个时间步保存原子替换断点。
相同模型、步长、时间和预算的重启可加载断点；不能以增加 maxdim 的名义复用此前低预算的演化。
最终代码快照为 source_final_20261001.tar，文件校验值见 source_final_sha256.json；保留早期和执行时快照。
服务器只在隔离 results 子目录内运行，最多 16 线程、nice=10、总时限 8 小时。

本机 Julia 1.11.5，服务器 Julia 1.12.3；ITensors 0.9.27、ITensorMPS 0.4.1 一致。
不同参数点不互相比作收敛对照。正参数的联合对照保留在本机原运行环境。
负参数使用服务器已收敛的同一基态，本机先计算提高预算对照。
实测本机演化显著更快，随后将完整负参数扫描重新独立放到本机进行，目录 L40_negative_local。
因此最终负参数的联合预算对照也使用相同本机运行环境，不混合不同环境的数据行。
服务器 L40_negative_converged 的部分断点保留为额外独立核验，不用于填补或镜像最终谱。
export_fullq_partial.jl 不加载 MPS，只读取断点中已真实计算的关联；已回收 17 个动量单元。
额外核验检查模型、基态能量和时间网格一致，关联相对差异须 <0.002；不裁剪、拼接或平均任何原始关联。
